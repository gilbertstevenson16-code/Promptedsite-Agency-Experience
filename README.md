# Promptedsite Agency Experience

Runtime media and portable interactive preview distribution for Promptedsite.
Editable template source is supplied separately with the product.

Canonical media is served from Cloudflare R2. GitHub Releases provide verified
fallback media and compiled previews for environments that cannot reach R2.

The standalone HTML contains the compiled React application and embedded media.
It requires JavaScript, WebGL, WebAssembly and blob workers; preview hosts may
apply additional sandbox restrictions.

The agency, pricing, testimonials, metrics and contact content are demonstration
data. Buyers must configure CTA, social and business destinations before launch.
